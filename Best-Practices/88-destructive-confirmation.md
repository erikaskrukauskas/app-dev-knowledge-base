# Destructive confirmation

An irreversible destructive action states its effect and requires a confirmation. A single mis-click is not enough when the contract says the action is destructive.

No current official page was opened for this rule. Confirm a primary source before treating it as tested.

Confirmation is not a substitute for authorization. See [Application security](06-application-security.md).

## Check

Start the destructive action and dismiss the confirmation. The fact is unchanged. Confirming it performs the action once.
