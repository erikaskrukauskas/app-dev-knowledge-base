# Retention period

Data the application does not need to keep has a retention period. When the period ends, the data is deleted or anonymized.

No current official page was opened for this rule. Confirm a primary source before treating it as tested.

A legal hold stops deletion and is itself recorded. See [Personal data deletion](75-personal-data-deletion.md).

## Check

Create a fact with a short retention and pass the period. Ordinary reads no longer return the payload.
