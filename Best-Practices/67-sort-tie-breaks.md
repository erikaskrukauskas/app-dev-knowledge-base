# Sort tie breaks

When two items compare equal on the requested sort, a stated tie break, usually a stable identifier, decides the order.

No current official page was opened for this rule. Confirm a primary source before treating it as tested.

Without a tie break, pages can skip or repeat items. See [Stable identifiers](14-stable-identifiers.md).

## Check

Create two items with the same sort key and page across them. Neither item appears twice or disappears.
