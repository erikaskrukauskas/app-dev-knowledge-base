# Empty states

An empty collection has an empty state that tells the person whether the list is actually empty or still loading, and what they can do next.

No current official page was opened for this rule. Confirm a primary source before treating it as tested.

The empty state is text, not color alone. See [Accessibility](08-accessibility.md) and [Loading states](90-loading-states.md).

## Check

Open a collection with no items. The screen shows the empty state and does not show an error.
