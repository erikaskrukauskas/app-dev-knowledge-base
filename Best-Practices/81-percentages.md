# Percentages

A percentage names its base and its scale. A bare fraction is not a percentage unless the contract says the base is one.

No current official page was opened for this rule. Confirm a primary source before treating it as tested.

Rounding of the displayed percentage is a separate rule. See [Rounding mode](82-rounding-mode.md).

## Check

Compute a percentage from a known base and numerator. The result matches the stated scale.
