# Conflict copy

When two edits conflict and the application cannot merge them safely, it keeps both and asks a person or a stated rule to resolve them.

No current official page was opened for this rule. Confirm a primary source before treating it as tested.

It does not drop one side silently. See [Conditional updates](11-conditional-updates.md).

## Check

Edit the same fact on two sides and sync. Both edits remain available until resolution.
