# Unsaved changes

Leaving a screen with unsaved edits asks for confirmation or saves a draft. It does not discard the edits silently.

No current official page was opened for this rule. Confirm a primary source before treating it as tested.

The check is an exercised user path. See [Verify, then record](04-verify-and-record.md) and [Draft versus committed](83-draft-versus-committed.md).

## Check

Type a change and trigger navigation away. The edit is still available or the person confirmed the discard.
