# Maker checker

A sensitive write can require a second authorized person to approve it. The maker and the checker are different people.

No current official page was opened for this rule. Confirm a primary source before treating it as tested.

The pending write is not the committed fact. See [Draft versus committed](83-draft-versus-committed.md) and [Audit actor](63-audit-actor.md).

## Check

Submit a sensitive write and approve it as the same person. It stays uncommitted. A different authorized checker commits it.
