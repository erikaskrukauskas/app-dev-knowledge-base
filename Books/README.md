# Books and references

This folder is a catalog of application-development references and original notes about them. It is not a library of book files.

## What to store

- Title, author, edition, and year.
- The application question the source helps answer.
- Original notes in your own words.
- A short quotation only when the exact wording is required, with a citation.

## What to leave out

- PDFs and ebook files. `.gitignore` ignores `*.pdf` as a backstop.
- Verbatim chapters or reconstructed passages.
- Scanned pages and bulk exports from a reading tool.

AI references belong in the AI knowledge base. Data and release references belong in those repos, under the same note-taking rule.

## Using a book in a session

Search your notes. Then check current official documentation before you apply a claim about a language, a UI platform, an HTTP feature, or a test tool. A book can explain a durable design idea and still be wrong about a current API or default.
